# Source Asset Library

This directory contains the original, unoptimized prototype assets downloaded from their publishers on October 16, 2026.

These files are an internal source library, not the game's public asset directory. Do not load entire packs from the application or copy this directory into a production build.

For implementation:

1. Select only the files needed by the current scene or system.
2. Copy selected files into the future `public/assets` structure with stable, descriptive names.
3. Normalize scale, palette, anchors, and audio format as needed without modifying the source copy.
4. Record any new source in the root `CREDITS.md` before committing it.
5. Optimize selected PNG and audio files and verify them on a phone.

All current packs and files are listed as CC0 on their individual source pages. Original Kenney `License.txt` files are retained in each Kenney pack directory. OpenGameArt provenance is recorded in the root credits file because those downloads do not include embedded license documents.
